# NOMA — живой мессенджер

Мессенджер с функциональностью уровня Telegram и собственным дизайном: чёрный OLED-фон, электрический синий свет, стекло в стиле iOS и пружинная анимация везде.

**Backend:** Python · FastAPI · SQLAlchemy (SQLite) · WebSocket
**Frontend:** React 18 · TypeScript · Vite · Zustand · Framer Motion
**Звонки:** WebRTC (peer-to-peer), сигнализация через WebSocket

---

## Быстрый старт

Нужны **Python 3.11+** и **Node.js 18+**.

**Windows (PowerShell):**

```powershell
.\start.ps1 -Demo
```

**Linux / macOS:**

```bash
./start.sh --demo
```

Откройте <http://localhost:8000>. Флаг `-Demo` / `--demo` создаёт демо-аккаунты с диалогами, группой и каналом:
вход `demo` / `noma1234` (а также `alina`, `maks`, `sofia`, `artem`, `kira` с тем же паролем — только для локальной разработки).

**Режим разработки** (backend с автоперезагрузкой + Vite с горячей заменой):

```powershell
.\start.ps1 -Dev
```

Фронтенд будет на <http://localhost:5173>, запросы к `/api`, `/ws` и `/media` проксируются на backend `:8000`.

## Что умеет

**Сообщения**
- Текст с форматированием: `**жирный**`, `__курсив__`, `~~зачёркнутый~~`, `` `код` ``, блоки ```` ``` ````, `||спойлер||` с анимацией частиц, ссылки и @упоминания
- Ответы (свайп влево на телефоне, кнопка при наведении на ПК), переход к цитате с подсветкой
- Реакции: быстрая панель + полный набор, **двойной клик — ❤️ со взрывом частиц**
- Редактирование (в т.ч. стрелкой ↑), удаление, закрепление, пересылка в несколько чатов с комментарием, «В Избранное»
- Множественный выбор: копирование, пересылка, удаление пачкой
- Галочки отправлено/прочитано, «печатает…», «записывает голосовое…», онлайн и «был(а) …»
- Черновики для каждого чата, поиск по сообщениям в чате, отправка без потерь (повтор при ошибке)

**Медиа**
- Фото и видео альбомами до 10 штук, превью перед отправкой, подпись, drag & drop и вставка из буфера
- Файлы любых типов с прогрессом загрузки, аудиофайлы с плеером
- **Голосовые сообщения**: удерживайте микрофон, потяните вверх — фиксация записи, влево — отмена; волна громкости, скорость 1×/1.5×/2×
- **Видео-кружки**: нажмите на микрофон один раз, чтобы переключиться на камеру
- Полноэкранный просмотрщик: свайпы, зум колесом/двойным кликом, лента миниатюр, скачивание

**Звонки**
- Аудио и видеозвонки 1-на-1, включение камеры прямо во время звонка, **демонстрация экрана**, смена камеры на телефоне
- Входящий звонок приходит в **NOMA Island**, звонок можно свернуть в остров и продолжать переписку
- История звонков с фильтром пропущенных, перезвон в один клик

**Чаты**
- Личные чаты, **группы** (владелец/админы/участники, добавление/удаление, назначение админов), **каналы** (пишут только админы)
- Публичные группы и каналы с поиском и вступлением по ссылке
- «Избранное» — личное облако, официальный аккаунт NOMA с приветствием
- Папки: Все / Личные / Группы / Каналы / Новые / Архив; закрепление чатов, без звука, архив

**Фирменные фишки дизайна**
- **NOMA Island** — «динамический остров»: входящие звонки, уведомления, активный звонок, плеер голосовых
- **Живой фон** — аврора медленно дрейфует, светится сильнее, когда собеседник печатает, и пускает «волну света» при новом сообщении
- **Фокус-меню** в стиле iOS: фон размывается, сообщение приподнимается, над ним — реакции, под ним — действия
- «Сейчас в сети» — ряд друзей онлайн с вращающимся градиентным кольцом
- **Spotlight (Ctrl + K)** — мгновенный переход к любому чату, человеку или действию
- 6 акцентных цветов (Электрик, Лёд, Кобальт, Индиго, Океан, Полночь), 4 фона, размер текста, скругление пузырей
- Все звуки синтезируются WebAudio — без аудиофайлов; системные уведомления, когда вкладка в фоне
- Полностью адаптивно: на телефоне — плавающий стеклянный таб-бар и iOS-навигация

## Структура

```

  app/
    main.py          — FastAPI-приложение, статика /media и собранного фронтенда
    models.py        — User, Chat, ChatMember, Message, Reaction
    services.py      — сериализация, рассылка событий, права

  seed_demo.py       — демо-данные

frontend/
  src/
    api/             — REST-клиент и типы
    store/           — Zustand: chats, call (WebRTC), player, ui, settings, auth
    components/      — sidebar, chat, message, composer, overlay (Island, CallScreen…), modals, info
    styles/          — дизайн-система (base, layout, chat, overlays)
```

## Настройка

Переменные окружения backend:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `NOMA_DATA_DIR` | `backend/data` | база SQLite, загрузки, секретный ключ |
| `NOMA_DATABASE_URL` | SQLite в `NOMA_DATA_DIR` | например, `postgresql+asyncpg://…` (нужен пакет `asyncpg`) |
| `NOMA_SECRET_KEY` | генерируется и сохраняется | ключ подписи JWT |
| `NOMA_MAX_UPLOAD_MB` | `512` | лимит размера файла |
| `NOMA_ICE_SERVERS` | публичные STUN Google | JSON со STUN/TURN-серверами для звонков |

### Звонки через интернет и с телефона

- Браузеры дают доступ к микрофону и камере только по **HTTPS** или на `localhost`. Чтобы открыть NOMA с телефона в локальной сети или в интернете, поставьте сервер за HTTPS (Caddy, nginx + Let's Encrypt).
- Между разными сетями (мобильный интернет ↔ Wi-Fi) прямое соединение часто блокирует NAT — нужен **TURN-сервер** (например, coturn):

```bash
NOMA_ICE_SERVERS='[{"urls":"stun:stun.l.google.com:19302"},{"urls":"turn:turn.example.com:3478","username":"noma","credential":"secret"}]'
```
